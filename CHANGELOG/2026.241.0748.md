# 2026.241.0748 — fix: bump spec pin to v0.2026241.711 (schema 2026.240.1943 support)

## Summary

The `plugin-deploy-vm` candy pinned `spec` v0.2026232.520 (schema max 2026.232.0520). The charly.yml migration to schema 2026.240.1943 — required by the GitClient spec cutover (spec#65, v0.2026241.711) — makes the old pin reject every project config at `prepare-venue` time:

```
resolve vm entity "charly-vm": config schema 2026.240.1943 is newer than this charly supports (max 2026.232.0520)
```

This blocks the `check-charly-vm` disposable bed (the R10 gate for the sdk git-layer wiring, sdk#182).

Bump `spec` to v0.2026241.711 (schema head 2026.240.1943) and `sdk` to v0.2026240.2049 (latest tag, compatible with the new spec).
